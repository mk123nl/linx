# 需求清单

## 一期（现在，纯界面）
- 顶部轮播图：当日推荐，点击跳转
- 四大分区：音乐 / 小说 / 广播剧 / 漫画
- 每区独立推荐页（先假数据，像网易云/QQ音乐）

## 二期（等有服务器 + 账号系统后）
- QQ邮箱登录
- 简单人机验证
- 评论区
- 向开发者反馈
- 每区智能推荐（根据用户行为）

## 三期（AI 助手，减轻人工）
- AI 内容审核：自动检查用户上传的图片/文字，过滤违规和垃圾
- AI 打标签 + 推荐：自动分类内容，给用户推喜欢的

## 一期补充3（"我的"页面）
- 入口1：官方QQ频道（二维码，点击全屏显示）
- 入口2：个人反馈（二维码，点击全屏显示）
- 图片先用占位，之后替换真实二维码
